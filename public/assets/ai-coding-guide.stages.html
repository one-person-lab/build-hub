四个阶段 · 一层层叠上来

AI 编程的四个阶段，和你该盯的东西

补全、对话、Agent、带工程的协作，是一层层叠上来的，今天仍有人只用补全。变的是它敢接的任务范围——你要管的东西跟着往上挪了一层。

阶段一

代码补全

Copilot 那几年

你写代码，它接下一段，少敲重复的字。

卡在哪：只看得到眼前几行，不知道整个需求。

阶段二

对话式开发

你说需求，它给代码

解释代码、写函数、看报错都行，复制粘贴归你。

卡在哪：上下文一断就得重讲，跨文件靠你来回搬。

阶段三

Agent 干活

现在的主力用法

你定任务和红线，它自己读项目、改文件、跑命令、来回迭代。

卡在哪：任务边界画不清、上下文给不够、敢改到哪一步、跑完拿什么算过。

阶段四

带工程的协作

正在成形的做法

Agent 进到有规范、有测试、有版本控制的流程里干活。

为的是什么：这次的产出来历查得到，下次不用重新赌一遍。

你要盯的东西，一路往上挪

这一句补全质量、提示词、单次输出
这一个文件接口对不对、报错怎么解
这件事任务说清没有、上下文够不够
这套流程权限、验证证据、风险控制、能不能退回

过去问「代码生成得快不快」，现在问「这个任务交出去能不能收回来」。前两个阶段没作废，只是不再是全部。

阶段一 · 代码补全你写它接下一段。卡在看不到整个需求。
阶段二 · 对话式开发你说需求它给代码。卡在上下文一断就重讲。
阶段三 · Agent 干活你定任务和红线。卡在边界、上下文、权限、验证。
阶段四 · 带工程的协作进规范、测试、版本控制。为的是下次还能照原样跑一遍。
你要盯的东西往上挪这一句 → 这一个文件 → 这件事 → 这套流程。
