## 1. 主题机制

- 样张 `redesign.css` 的 `rd-*` 令牌升级为全站 CSS 变量，替换 `globals.css`/`vibehub.css` 中的 `--bg/--card/--border/--text` 色阶：
  - 深色：底 #14151a / 卡 #202228 / 线 #2c2f38 / 正文 #ECEEF2 / 弱化 #8B8E99 / 更弱 #5C5F69 / accent #E8C767
  - 浅色：底 #f7f7f8 / 卡 #fff / 线 #e4e4e7 / 正文 #1a1b20 / accent #8a6a1f / 选中奶油底 #fbf3dc
- 接入现有 `document.documentElement.dataset.colorMode`（localStorage `vh-color-mode`）与主题色切换（`vh-theme-color`）：accent 默认金色，用户切换主题色时 accent 联动。
- 选中态交互约定（深浅不同但布局相同）：深色 = 金色描边/金点，浅色 = 奶油底。

## 2. 导航（SiteNav → 图鉴式导航）

- 结构照搬样张：✦ 图标 + BuildHub 驼峰字标 / 分区菜单（术语·技能·产品·提示词）/ 素材库胶囊 / 搜索按钮（`/` 或 ⌘K 开命令面板，↑↓↵esc，回车跳词条）/ Go Pro / 深浅切换 / 头像菜单（收收藏等现有入口）。
- 滚动常驻（sticky top 0，毛玻璃底）；<900px 降级：隐藏分区菜单与胶囊文字，搜索收成图标。
- 现站 nav 的交流群、练习、路线等入口移入头像菜单，不丢功能。

## 3. 列表页（CatalogView / SkillLibrary / ProductLibrary / PromptLibrary / AssetLibrary → 图鉴列表）

- 卡片：demo 缩略取景框（统一 16:9、`--preview-scale` 按容器宽自动缩放；无 demo 的卡片不加占位图、不加字母图标），下方名称+英文名+一句话。
- 吸顶两层：导航（56px）+ 分区筛选条（毛玻璃底）；锚点跳转与滚动判定线为两层让位。
- 左侧实时目录：安静文字列（无底色无边框），当前分组 = 提亮加粗 + 4px accent 圆点淡入，条数淡显；窄屏 <980px 隐藏；不做底部渐隐蒙版。
- 保留现版全部功能：收藏、卡片/列表视图切换、平台筛选（全部/Web/iOS）、中英文切换、搜索结果。

## 4. 详情页（TermDetail / SkillDetail / ProductDetail / PromptDetail / AssetDetail）

- 换图鉴外壳：深色卡底、金色 kicker、侧边目录同款安静样式、场景图/demo 沿用 `.scaled-preview` 取景机制。
- 内容结构不动：典型使用场景、原则、区别、提示词、参考链接各 section 原样迁移。
- 深浅双态交互约定与全站一致（§1）。
